# A Categorization of Artificial Intelligence Approaches in Business Process Management

**Authors:** Rebecca Okine, Cara Scheuringer  
**Institution:** Hasso Plattner Institute, University of Potsdam

## About

This repository contains the replication materials for a systematic literature 
review (SLR) that categorizes 229 peer-reviewed papers at the intersection of 
Artificial Intelligence (AI) and Business Process Management (BPM).

Papers are classified using:
- The nine-category AI taxonomy from Russell and Norvig (2022)
- The four-phase BPM lifecycle from Weske (2024)

## Repository Contents

| Sheet | Description |
|---|---|
| Seed Papers | Initial known papers used to verify search coverage |
| Search String | Exact Scopus query used to retrieve the 809 candidates |
| 809 - SLR | All 809 records with title and abstract screening decisions |
| 809 - Full text screening | Full-text review with final inclusion decision and reasoning for AI category and BPM phase assignments |
| Included Papers | Final corpus of 229 included papers with AI category and BPM lifecycle phase assignments |
| Excluded Papers | Papers removed during screening with the exclusion criterion applied |
| Coding Scheme | Inclusion criteria (IC1–IC4) and exclusion criteria (EC1–EC7) |
